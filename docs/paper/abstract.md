## Abstract

We introduce the Hierarchical Excitable Unit (HEU), a continuous-time dynamical system for event commitment in temporal signals. The HEU maps continuous excitation to a bounded envelope state, emits discrete spikes at threshold crossings, and enforces refractory suppression—all governed by four interpretable parameters exposed through a normalized interface.

Our central contribution is a constructive impossibility result. We exhibit a temporal target requiring fast transient decay followed by stable sustain—dynamics that demand conflicting parameter settings. Single-voice HEU optimization consistently saturates 3 of 4 parameters at their bounds while achieving 21× worse loss than a minimal two-voice architecture, with a 2888× improvement in the critical region. The impossibility arises from parameter coupling: a single balance parameter trades off attack against recovery, preventing any configuration from satisfying both requirements. Assigning independent parameters to independent voices resolves the conflict.

We validate the HEU through four experiments: tempo locking (PLV = 1.0 across 90–140 BPM), multi-voice stability, parameter optimization for musical articulations (loss < 0.001), and the single-voice impossibility proof. We apply the HEU to polyphonic audio transcription, where the same bottleneck manifests as note fragmentation—3–5× over-detection at correct pitch. Stabilizing the dynamics yields an order-of-magnitude F1 improvement (0.054 → 0.731) on piano content.

The HEU is a minimal, non-learning system not intended to compete with state-of-the-art learned models. Its value is making expressivity limits explicit: globally coupled parameters impose strict representational limits on temporal patterns with conflicting requirements, and independent dynamical state resolves them. This is not an asymptotic claim, but a concrete, quantified separation demonstrated in both controlled experiments and practical application.
